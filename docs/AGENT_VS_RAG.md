# RAG와 Agent 비교

같은 질문, 교과서, 검색 범위와 현재 페이지를 사용한다. RAG는 검색 후 설명하고, Agent는 이해 부족을 확인해 선수 개념 검색, 진단 문제, 답변 평가, 학습 상태 갱신과 추천을 수행한다. 실제 비교에서는 모델·문맥·예산을 고정하고 응답 시간과 토큰을 함께 기록해야 한다.

`scripts/evaluate.py`는 합성 PDF 2개와 동일한 질문 12개를 사용하는 기존 오프라인 도구·상태 비교다. 양쪽의 출처 일치 12/12, Agent의 문제 복원·오답 상태 갱신·복습 추천·중복 기록 방지 각각 12/12를 확인했다. 도구 실행 횟수는 실제 학습 효과를 의미하지 않는다.

실제 교과서 검색은 24개 사례에서 별도로 평가한다. 최신 복구 결과는 [학습 평가](LEARNING_EVALUATION.md)를 참조한다. 실제 Bishop의 Bayes 다중 턴 평가와 유료 호출 준비는 [승인 전 점검](BAYES_LIVE_PREFLIGHT.md)을 참조한다.

실제 모델 응답은 독립 평가자가 같은 9개 항목으로 검토해야 한다. 사용자 이해도 향상에는 참여자 동의, 사전·사후 시험과 대조 조건이 필요하며 현재 이 실험은 수행하지 않았다.
