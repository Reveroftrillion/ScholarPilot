# ScholarPilot 실사용 평가 요약

고유 사례 147개, 별도 API 재실행 34개, 실제 Ollama 생성 189회, 책·페이지 48개, 고유 브라우저 20개.

상대 페이지·비교 조회, 선택문 검증, 번역 범위, 검색 근거 없음 처리, 표·그래프 추측 차단과 퀴즈 형식을 보완했다. 실제 재생성으로 기능 개선을 확인했으나 수학·개념·다의어 번역의 오류는 남는다. 출처가 유효하다는 이유로 답변을 정확하다고 판정하지 않았다. 우선 과제는 근거에 충실한 설명과 수식 의미의 신뢰성, 16GB RAM 환경의 메모리 압박이다. 그림 직접 해석은 미지원이다.
