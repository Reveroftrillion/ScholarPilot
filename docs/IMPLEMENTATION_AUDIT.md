# 실제 코드 진단 및 수정 결과

| Markdown / LaTeX | 부분 구현: 일부 구분자 미지원 | 코드 보존·구분자 변환. 브라우저 KaTeX 표시 확인 |

| 선수 개념 | Mock 정규식 후보 추출 | 실제 모델 후보 선택→근거 검색·이력 확인 연결. 의미적 타당성 미검증 |

| 오답·이해도 | 규칙 기반 부분 구현 | 실제 답안 채점→선수 개념·피드백·복습 상태·추천 연결 테스트 |
| 진단 문제 복원 | 부분 구현: 후속 응답에서 문제 소실 | 미제출 문제 재노출·중복 생성 방지. 새로고침→제출 확인 |
| 새 대화·문장 저장·삭제·책 전환 | 연결됨, 선택 경합·삭제 오류 표시 누락 | 오류 수정. 실제 저장·목차 확인·책 전환 검증 |
| AI 설정·연결 테스트 | 부분 구현: 환경변수 안내만 제공 | 무료 설정 검사·명시적 승인 후 유료 1회 검사. 승인 없는 호출 차단 테스트 |
| 테스트 | 일부 성공, Windows 이벤트 루프 오류 | HTTP 루프 재사용·DB 격리. 백엔드 29개·프론트엔드 2개·브라우저 5개 통과 |

실제 OpenAI 키가 없으므로 번역·유도 정확성, 문제 품질, 의미 채점 정확성은 미검증입니다. 대역 모델은 응답에 `오프라인 모델 대역`을 표시하며 사용자 DB와 격리됩니다. OCR, 임베딩 검색, 이미지 영역 분석, 복습 스케줄은 미구현입니다.

## 2차 검증·수정

| 기능 | 코드 및 추가 검증 근거 | 현재 판정 |
|---|---|---|

| 동시 퀴즈·중복 제출 | `backend/learning.py`, `tests/test_retrieval_quality.py` | 격리 DB 8개 동시 요청에서 문제·답안 각각 1개 저장, 기존 채점 유지 |
| 문제 정답 비공개 | `backend/agent.py`, `tests/test_retrieval_quality.py` | 제출 전 생성 도구의 정답·해설 로그 마스킹 확인 |

| 복원·긴 대화·검색 안내 | `frontend/src/main.tsx`, `frontend/e2e/live-contract.spec.ts`, `docs/restart-test.json` | 마지막 책 자동 복원, 서버 재시작 후 퀴즈 복원, 채팅 영역 스크롤·결과 없음·오류 표시 확인 |

| 기본 보안·격리 | `.gitignore`, `tests/test_ingestion_atomic.py`, `tests/test_page_context.py`, `scripts/browser_fixture.py` | 경로·프롬프트 주입 도구 제한·PDF/키 제외·사용자 DB와 별도 QA 확인. 정규식 키 검색만으로 모든 비밀 부재를 보장하지 않음 |

최종 자동 테스트는 백엔드 47개, 프론트엔드 2개, 격리 브라우저 6개 통과했습니다. 실제 AI 연결과 설명·채점 정확도는 API 키가 없어 검증하지 않았습니다.
